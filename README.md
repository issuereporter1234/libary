# Library

A browser-based app for tracking your reading list. Built as part of [The Odin Project](https://www.theodinproject.com/) curriculum. Add books, mark them as read or unread, and remove them from your collection.

🔗 [Live Demo](https://issuereporter1234.github.io/libary/)

## Features

- View a list of books with title, author, and page count
- Add new books via a form
- Toggle read/unread status for each book
- Delete books from the library

## Tech Stack

- HTML
- CSS
- JavaScript (vanilla, no frameworks)

## How to Use

Clone the repo and open `index.html` in your browser — no installation required.

```bash
git clone https://github.com/issuereporter1234/libary
cd libary
```
